# ToolRent Pro

Тестовый проект: веб-сервис для аренды строительного инструмента и оборудования.

## Как открыть
1. Распакуйте ZIP.
2. Откройте `index.html` двойным кликом.

## Возможности
- Каталог из 12 единиц инструмента и оборудования.
- Drag & drop сортировка карточек.
- Сохранение порядка и выбранного заказа в localStorage.
- Тёмная/светлая тема.
- Поиск, фильтры, сортировка.
- Калькулятор аренды, залога и доставки.
- Проверка заказа и мини-график.
- Экспорт заказа в JSON.
- Кнопка сброса настроек.

# PCForge Pro — конфигуратор ПК онлайн

Откройте `index.html` двойным кликом. Сайт не требует сборщика, npm или сервера.

Что внутри:
- адаптивный сайт-конфигуратор системных блоков;
- drag & drop сортировка карточек с сохранением в localStorage;
- тёмная/светлая тема;
- поиск, фильтр, подсветка результатов;
- расчёт стоимости, ваттности, рекомендуемого БП;
- проверка совместимости CPU / motherboard / RAM / PSU;
- экспорт текущей сборки в JSON;
- офлайн-дружественные SVG-изображения комплектующих.

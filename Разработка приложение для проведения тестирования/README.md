# TestFlow — приложение для проведения тестирования

Откройте `index.html` двойным кликом. Проект не требует сборки и интернета.

## Возможности
- Каталог тестов из 8 карточек
- Drag & drop с сохранением порядка
- Тёмная/светлая тема
- Сброс настроек
- Умный поиск и фильтр категорий
- Демо-прохождение теста
- Конструктор сценария тестирования
- Настройки времени, проходного балла и античита
- Экспорт состояния в JSON
- Адаптивный интерфейс
